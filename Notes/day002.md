# Day 2 - The Birth of Learning

## Objective

Understand how a mathematical function can learn.

## Traditional Model

prediction = input × 2

The programmer supplies the rule.

## Learnable Model

prediction = input × w

where `w` is unknown.

The goal of training is to discover the best value of `w`.

## Loss

Loss measures how wrong a prediction is.

Examples:

Absolute Loss

|prediction - actual|

Squared Loss

(prediction - actual)^2

## Why Square the Error?

Positive and negative errors should not cancel each other.

Large mistakes are penalized more heavily than small mistakes.

## Important Insight

Loss only tells us **how wrong** the prediction is.

Loss does **not** tell us which direction to change the parameter.

That requires gradients.
