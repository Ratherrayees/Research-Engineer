# Math for AI — Day 1

## Mathematical Language, Quantities, Relationships, and Algebra Foundations

---

## 1. What Mathematics Is Doing in AI

Mathematics is a language for describing:

* Quantities
* Relationships between quantities
* How quantities change
* How one quantity affects another
* Uncertainty
* Optimization

AI uses all of these.

For example, during neural-network training there may be a particular weight:

[
w
]

The model produces some loss:

[
L
]

Training ultimately needs to understand the relationship:

[
w \rightarrow L
]

More specifically:

> If the value of (w) changes, what happens to (L)?

That simple question eventually leads to calculus, derivatives, gradients, gradient descent, and backpropagation.

But all of those advanced ideas are built from much simpler mathematical concepts.

---

# 2. Quantities

A **quantity** is something that can be represented numerically.

In AI engineering, quantities might include:

* Number of tokens
* GPU memory
* Training loss
* Learning rate
* Number of parameters
* Model accuracy
* Embedding dimensions
* Execution time
* Token probabilities
* Weight values

For example:

[
4096
]

could represent a context length.

However, the number itself does not tell us what it represents.

Context gives the number meaning.

For example:

[
4096 \text{ tokens}
]

and:

[
4096 \text{ bytes}
]

contain the same numerical value but represent completely different quantities.

---

# 3. Mathematical Operations

The basic mathematical operations are:

[
+,\quad -,\quad \times,\quad \div
]

For AI, it is more useful to understand what these operations mean than to simply know how to calculate them.

---

## Addition — Combining Contributions

Addition combines quantities.

For example:

[
a+b
]

means that the contribution represented by (a) and the contribution represented by (b) are being combined.

This happens constantly inside neural networks.

Consider:

[
wx+b
]

The term:

[
+b
]

means that another quantity is being added to the contribution produced by:

[
wx
]

Later, neurons will perform operations such as:

[
w_1x_1+w_2x_2+w_3x_3+\cdots+b
]

Each input contributes something, and addition combines those contributions.

A useful mental model is:

[
\boxed{\text{Addition often means accumulating contributions}}
]

---

# 4. Subtraction — Measuring Difference

Subtraction allows us to compare quantities.

For example:

[
a-b
]

describes the difference between (a) and (b).

This becomes extremely important in machine learning.

Suppose:

[
y
]

represents the correct answer and:

[
\hat y
]

represents the model's prediction.

We might calculate:

[
\hat y-y
]

If:

[
\hat y=80
]

and:

[
y=100
]

then:

[
80-100=-20
]

The result is not merely telling us that the prediction is 20 away.

The negative sign also gives us directional information.

It tells us that the prediction is below the target.

This distinction between **size** and **direction** becomes very important later when we study gradients.

---

# 5. Positive and Negative Numbers

Think of zero as a reference point:

[
\cdots,-3,-2,-1,0,1,2,3,\cdots
]

Positive and negative values can represent opposite directions relative to zero.

For example, a neural-network weight might be:

[
w=0.8
]

or:

[
w=-0.8
]

These values have the same magnitude but opposite signs.

Their effect inside the model can therefore be very different.

Later, we will encounter things such as:

[
\frac{dL}{dw}>0
]

and:

[
\frac{dL}{dw}<0
]

The sign will help tell us which direction a parameter should move.

A useful mental model is:

[
\boxed{\text{Sign often carries directional information}}
]

---

# 6. Multiplication — Scaling

Multiplication is often introduced as repeated addition.

For AI, however, a more useful way to think about multiplication is:

> Multiplication scales one quantity by another.

Suppose:

[
x=10
]

and:

[
w=2
]

Then:

[
wx=20
]

The input has been scaled upward.

If:

[
w=0.5
]

then:

[
wx=5
]

The input has been scaled downward.

If:

[
w=0
]

then:

[
wx=0
]

The contribution disappears.

If:

[
w=-2
]

then:

[
wx=-20
]

The magnitude becomes larger and the sign changes.

Therefore:

[
\boxed{\text{Multiplication can control the strength and direction of a quantity}}
]

This is extremely important in neural networks.

---

# 7. Why Neural Networks Have Weights

Consider:

[
wx
]

where:

* (x) = input
* (w) = weight

The weight scales the input.

If:

[
w=1
]

then:

[
wx=x
]

The magnitude remains unchanged.

If:

[
w=0.1
]

the contribution becomes much smaller.

If:

[
w=5
]

the contribution becomes much larger.

If:

[
w=-1
]

the sign is reversed.

A useful first intuition for neural-network weights is:

[
\boxed{\text{A weight controls how strongly an input contributes}}
]

We will refine this idea later when we study full neurons and neural networks.

---

# 8. Division — Relative Quantity and "Per"

Division does more than split quantities.

It also describes one quantity relative to another.

Suppose a training system processes:

[
120000 \text{ tokens}
]

in:

[
30 \text{ seconds}
]

Then:

[
\frac{120000}{30}=4000
]

which means:

[
4000 \text{ tokens per second}
]

The word **per** is important.

Division frequently represents:

> One quantity relative to another quantity.

This idea later appears in:

* Rates
* Ratios
* Probabilities
* Averages
* Slopes
* Derivatives

---

# 9. Fractions

A fraction such as:

[
\frac{a}{b}
]

means:

[
a\div b
]

But fractions are especially useful because they represent relationships between quantities.

Suppose a dataset contains:

[
800
]

successful samples out of:

[
1000
]

samples.

Then:

[
\frac{800}{1000}=0.8
]

which is equivalent to:

[
80%
]

Therefore:

[
\frac{4}{5}=0.8=80%
]

Fractions, decimals, and percentages are often different representations of the same relationship.

---

# 10. Ratios

A ratio compares two quantities.

Suppose one machine-learning system uses:

[
8 \text{ GPUs}
]

while another uses:

[
4 \text{ GPUs}
]

Then:

[
\frac{8}{4}=2
]

The first system has twice as many GPUs.

Ratios appear throughout AI engineering:

* Train/test splits
* Compression ratios
* Aspect ratios
* Learning-rate changes
* Parameter scaling
* Memory efficiency
* Throughput comparisons
* Probability ratios

The core question behind a ratio is:

> How large is one quantity relative to another?

---

# 11. Percentages

A percentage means:

> Out of 100.

For example:

[
75%
]

means:

[
\frac{75}{100}
]

which equals:

[
0.75
]

Therefore:

[
75%=0.75
]

Machine-learning probabilities and performance metrics are often represented using decimals.

For example:

[
0.92
]

and:

[
92%
]

represent the same proportion.

---

# 12. Decimal Numbers

Neural networks mostly work with numbers that are not neat integers.

Weights might look like:

[
0.173
]

[
-0.842
]

[
0.006
]

Decimals represent parts of a whole.

For example:

[
0.5=\frac{1}{2}
]

[
0.25=\frac{1}{4}
]

[
0.1=\frac{1}{10}
]

Decimals and fractions are simply different ways of representing numbers.

---

# 13. Variables

A **variable** is a symbol used to represent a quantity.

For example:

[
x
]

The letter (x) does not inherently mean anything.

Its meaning comes from context.

For example:

[
x=\text{number of input tokens}
]

or:

[
x=\text{temperature}
]

or:

[
x=\text{pixel intensity}
]

or:

[
x=\text{input feature}
]

The letter is simply a convenient name for a quantity.

---

# 14. Why Variables Exist

Suppose some quantity follows this relationship:

[
1\rightarrow2
]

[
2\rightarrow4
]

[
3\rightarrow6
]

[
4\rightarrow8
]

We could continue calculating individual cases forever.

Instead, algebra allows us to describe the entire relationship using:

[
y=2x
]

Now (x) can represent any allowed input.

This is one of the main powers of algebra:

[
\boxed{\text{Algebra describes general relationships instead of individual cases}}
]

---

# 15. Constants

Consider:

[
y=2x
]

Here:

[
x
]

can vary.

But:

[
2
]

is fixed.

A fixed numerical value is called a **constant**.

So:

[
\boxed{\text{Variable = value allowed to vary}}
]

[
\boxed{\text{Constant = value treated as fixed}}
]

However, whether something is considered fixed depends on the situation.

This distinction becomes especially important in machine learning.

---

# 16. Parameters

Consider:

[
y=wx+b
]

Here:

* (x) = input
* (w) = weight
* (b) = bias
* (y) = output

The values:

[
w
]

and:

[
b
]

are often called **parameters**.

A parameter is:

> A value that controls the behavior of a mathematical model.

In machine learning, parameters are usually learned from data.

---

# 17. Inputs vs Parameters

Consider again:

[
y=wx+b
]

During inference, the model receives:

[
x
]

The model already has particular values for:

[
w
]

and:

[
b
]

Different input data changes (x).

The learned parameters remain fixed while that prediction is being produced.

During **training**, however, the system changes:

[
w
]

and:

[
b
]

because training is trying to improve the model.

Therefore:

[
\boxed{\text{Data provides inputs}}
]

while:

[
\boxed{\text{Training learns parameters}}
]

This is one of the most important distinctions in machine learning.

---

# 18. What "7 Billion Parameters" Means

When a model is described as having:

> 7 billion parameters

it does not mean that the model contains exactly 7 billion written facts.

At the mathematical level, it means the model contains billions of learned numerical values.

Very abstractly:

[
w_1,w_2,w_3,\ldots,w_n
]

and many other learned values.

Training adjusts those numbers so that the overall mathematical system develops useful behavior.

Knowledge is distributed across patterns in these parameters and their interactions.

One of the central questions of model training therefore becomes:

> How should each parameter change so that the model improves?

That question eventually leads us to gradients and backpropagation.

---

# 19. Expressions

Consider:

[
3x+5
]

This is a mathematical **expression**.

An expression represents a value produced through mathematical operations.

For example:

[
wx+b
]

means:

1. Multiply (w) by (x).
2. Add (b).

The expression produces a value.

But we have not yet given that result a name.

---

# 20. Equations

Now consider:

[
y=3x+5
]

This is an **equation**.

An equation states that the quantity on the left and the quantity on the right have the same value.

Therefore the equals sign:

# [

]

should be understood as:

> Has the same value as.

It does not simply mean:

> Here comes the answer.

---

# 21. Equality and Balance

Suppose:

[
x+5=12
]

This tells us that:

[
x+5
]

must have exactly the same value as:

[
12
]

To determine (x), subtract 5 from both sides:

[
x+5-5=12-5
]

which gives:

[
x=7
]

A common shortcut says:

> Move the 5 to the other side and change its sign.

But mathematically, nothing actually moved.

We performed the same operation on both sides.

If:

[
A=B
]

then subtracting the same quantity (c) from both sides gives:

[
A-c=B-c
]

Equality remains preserved.

This is the real foundation of algebraic manipulation.

---

# 22. Why Algebraic Manipulation Matters for AI

Later, we will encounter equations where we need to isolate particular quantities.

Instead of memorizing rules such as:

* Move this to the other side
* Flip the sign
* Invert this
* Cross-multiply that

we will understand every operation through the idea of preserving equality.

This makes advanced equations much easier to reason about.

---

# 23. Hidden Multiplication in Mathematical Notation

Mathematics often removes the multiplication symbol.

So:

[
2x
]

means:

[
2\times x
]

Similarly:

[
wx
]

means:

[
w\times x
]

And:

[
3xy
]

means:

[
3\times x\times y
]

Therefore:

[
wx+b
]

can mentally be read as:

[
w\times x+b
]

until the notation becomes natural.

---

# 24. Parentheses

Parentheses tell us to treat something as one unit.

Consider:

[
2(x+3)
]

This means:

[
2\times(x+3)
]

The 2 scales everything inside the parentheses.

Therefore:

[
2(x+3)
]

becomes:

[
2x+6
]

because:

[
2(x+3)
======

2\times x+2\times3
]

which gives:

[
2x+6
]

This is called the **distributive property**.

It becomes extremely important as equations become larger.

---

# 25. Order of Operations

Consider:

[
2+3\times4
]

Without agreed rules, someone might interpret this as:

[
(2+3)\times4=20
]

while someone else might interpret it as:

[
2+(3\times4)=14
]

Mathematics therefore uses a standard order of operations.

Multiplication and division happen before addition and subtraction unless parentheses change the structure.

Therefore:

[
2+3\times4
]

means:

[
2+(3\times4)
]

which gives:

[
14
]

But:

[
(2+3)\times4
]

means:

[
5\times4=20
]

The deeper idea is:

[
\boxed{\text{Mathematical expressions have structure}}
]

Parentheses allow us to explicitly control that structure.

---

# 26. Read Equations as Relationships

One of the most important habits in AI mathematics is learning to translate symbols into meaning.

When you see:

[
y=3x+5
]

do not merely read:

> y equals three x plus five.

Instead understand:

> (y) depends on (x).

> The contribution from (x) is scaled by 3.

> A fixed amount of 5 is added.

> The final result is called (y).

Similarly:

[
z=wx+b
]

should mean:

> Input (x) is scaled by weight (w), bias (b) is added, and the result is called (z).

This ability to translate equations into processes is much more useful than memorizing formulas.

---

# 27. Our First Important AI Equation

The most important equation from Day 1 is:

[
\boxed{z=wx+b}
]

Let's understand every piece.

### (x) — Input

The quantity entering the computation.

### (w) — Weight

A parameter controlling how strongly (x) contributes.

### (wx)

The weighted or scaled contribution of the input.

### (b) — Bias

Another parameter added independently of the input.

### (z) — Result

The value produced by the whole calculation.

Structurally:

[
x
\xrightarrow{\times w}
wx
\xrightarrow{+b}
z
]

In words:

> Take an input, scale it using a learned parameter, add another learned parameter, and produce a result.

We have not yet fully studied a neuron.

But this equation is one of the mathematical foundations from which neural networks are built.

# Day 1 Mental Checkpoint

By the end of Day 1, this equation:

[
\boxed{z=wx+b}
]

should not look like random mathematical symbols.

You should be able to read it as:

> (x) is an input.

> (w) controls how strongly the input contributes.

> The input is multiplied by (w).

> (b) adds an independent baseline.

> The resulting value is called (z).

Most importantly, you should understand why mathematics uses symbols like (x), (w), and (b):

> They allow us to describe general relationships that work across many different numerical values instead of writing a separate calculation for every possible case.
