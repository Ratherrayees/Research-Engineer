# Math for AI — Day 4

## Variables, Functions, Graphs, Slope, Intercept, Weight, Bias, and the First Mathematical Model of a Neuron

---

# 1. What Day 4 Is About

Day 4 is where several pieces of basic mathematics begin connecting directly to machine learning.

The most important equation for today is:

[
\boxed{z=wx+b}
]

By the end of Day 4, this equation should no longer look like random algebra.

We want to understand:

* What (x) represents
* What (w) represents
* What (b) represents
* What (z) represents
* Why multiplication appears
* Why addition appears
* How this equation becomes a graph
* What slope means
* What an intercept means
* Why weight behaves like slope
* Why bias behaves like an intercept
* How changing (w) and (b) changes the model's behavior

This is one of our first major bridges between:

[
\text{basic algebra}
]

and:

[
\text{neural networks}
]

---

# 2. Variables Revisited

A **variable** is a name given to a quantity whose value can vary.

For example:

[
x
]

could represent:

* an input feature
* temperature
* token count
* pixel value
* model input
* some intermediate value

Suppose:

[
x=5
]

Then (x) currently represents 5.

But later:

[
x=10
]

could also be valid.

The symbol (x) itself does not permanently mean any particular number.

It represents a quantity.

---

# 3. Why Mathematics Uses Variables

Suppose electricity costs ₹8 per unit.

If we use:

[
10
]

units, the bill is:

[
8\times10=80
]

If we use:

[
50
]

units:

[
8\times50=400
]

If we use:

[
100
]

units:

[
8\times100=800
]

Instead of writing a separate calculation for every possible amount, we can define:

[
x=\text{units consumed}
]

and:

[
y=\text{total cost}
]

Then write:

[
y=8x
]

This one equation represents every possible input.

That is one of the main purposes of variables:

[
\boxed{\text{Variables allow us to describe general relationships}}
]

---

# 4. A Variable Is Not Necessarily a Mystery Number

Consider:

[
x+5=10
]

Here (x) is an unknown.

We want to determine:

[
x=5
]

But consider:

[
y=2x+3
]

Here (x) is not one hidden number.

It can take many values.

If:

[
x=1
]

then:

[
y=5
]

If:

[
x=2
]

then:

[
y=7
]

If:

[
x=10
]

then:

[
y=23
]

So in functions and machine learning, variables frequently represent:

> quantities that are allowed to change

rather than:

> mystery values that must be solved.

---

# 5. Hidden Multiplication

Mathematics usually removes the multiplication sign between variables and coefficients.

So:

[
2x
]

means:

[
2\times x
]

Likewise:

[
wx
]

means:

[
w\times x
]

And:

[
3xy
]

means:

[
3\times x\times y
]

Therefore, when we see:

[
wx+b
]

we should mentally understand:

[
(w\times x)+b
]

This notation appears everywhere in machine learning.

---

# 6. Expressions

Consider:

[
3x+4
]

This is an **expression**.

An expression represents a mathematical value or computation.

It tells us:

1. Take (x)
2. Multiply it by 3
3. Add 4

But it does not yet say what the result is called.

If:

[
x=2
]

then:

[
3x+4
]

becomes:

[
3(2)+4
]

which gives:

[
10
]

So the expression evaluates to 10 for that particular value of (x).

---

# 7. Equations

Now consider:

[
y=3x+4
]

This is an **equation**.

The equals sign:

# [

]

states that the quantity on the left has the same value as the quantity on the right.

So:

[
y=3x+4
]

means:

> Whatever value the expression (3x+4) produces, call that value (y).

This equation defines a relationship between:

[
x
]

and:

[
y
]

---

# 8. Expression vs Equation

Compare:

[
3x+4
]

with:

[
y=3x+4
]

The first is an expression.

It represents a value.

The second is an equation.

It tells us that the output (y) equals that expression.

So:

[
\boxed{\text{Expression = mathematical value/computation}}
]

while:

[
\boxed{\text{Equation = statement relating quantities}}
]

---

# 9. Equations Can Play Different Roles

Consider:

[
x+3=10
]

This equation contains an unknown to solve.

Now:

[
y=2x+3
]

This equation describes a relationship.

And:

[
2(x+3)=2x+6
]

is true for every valid value of (x).

So equations are not always used for exactly the same purpose.

The meaning depends on context.

---

# 10. Equality Means Balance

Suppose:

[
x+3=10
]

To isolate (x), subtract 3 from both sides:

[
x+3-3=10-3
]

Therefore:

[
x=7
]

It is common to hear:

> Move the 3 to the other side.

But technically, nothing moved.

We applied the same operation to both sides.

This preserves equality.

The deeper idea is:

[
\boxed{\text{Whatever valid operation we perform on one side, we perform on the other}}
]

This is the foundation of algebra.

---

# 11. Functions

A **function** is a rule that takes input and produces output.

Suppose:

[
f(x)=2x+3
]

The function is called:

[
f
]

Its input is:

[
x
]

Its rule is:

[
2x+3
]

So the function says:

> Take the input, multiply it by 2, add 3, and return the result.

---

# 12. What Does (f(x)) Mean?

The notation:

[
f(x)
]

does NOT mean:

[
f\times x
]

Instead, it means:

> Give (x) to the function (f).

Suppose:

[
f(x)=2x+3
]

Then:

[
f(4)
]

means:

> Give the value 4 to this function.

Replace (x) with 4:

[
f(4)=2(4)+3
]

Therefore:

[
f(4)=11
]

---

# 13. Function as a Machine

A useful mental picture is:

[
\boxed{
\text{input}
\rightarrow
\text{rule}
\rightarrow
\text{output}
}
]

For:

[
f(x)=2x+3
]

we have:

[
x
\rightarrow
2x+3
\rightarrow
f(x)
]

For:

[
x=4
]

the flow becomes:

[
4
\rightarrow
11
]

The function receives one value and transforms it into another.

---

# 14. Why Functions Matter in AI

A machine-learning model can itself be viewed as a function.

Very abstractly:

[
\text{output}=\text{model}(\text{input})
]

For an image classifier:

[
\text{class probabilities}
==========================

\text{model}(\text{image})
]

For a language model:

[
\text{next-token probabilities}
===============================

\text{model}(\text{previous tokens})
]

The real model might contain billions of operations.

But conceptually it still behaves like:

[
\boxed{
\text{input}
\rightarrow
\text{transformation}
\rightarrow
\text{output}
}
]

---

# 15. Functions Can Have Multiple Inputs

A function can receive more than one input.

For example:

[
f(x_1,x_2)
]

means the function receives:

[
x_1
]

and:

[
x_2
]

Suppose:

[
f(x_1,x_2)=2x_1+3x_2
]

Then both inputs contribute to the final output.

This becomes much closer to real machine learning because models usually process many values simultaneously.

---

# 16. Functions Can Be Chained

Suppose:

[
f(x)=2x
]

and:

[
g(x)=x+3
]

Take:

[
x=5
]

First:

[
f(5)=10
]

Then feed that result into (g):

[
g(10)=13
]

So:

[
5
\rightarrow
10
\rightarrow
13
]

One function's output becomes another function's input.

This is extremely important because neural networks are essentially enormous chains of transformations.

Very roughly:

[
\text{input}
\rightarrow
\text{layer 1}
\rightarrow
\text{layer 2}
\rightarrow
\text{layer 3}
\rightarrow
\text{output}
]

---

# 17. From Equations to Graphs

Consider:

[
y=2x+3
]

The equation tells us mathematically how (y) depends on (x).

A **graph** shows that same relationship visually.

Therefore:

[
\boxed{\text{Equation}\leftrightarrow\text{Graph}}
]

They are two representations of the same relationship.

---

# 18. The X-Axis and Y-Axis

A basic graph contains:

* a horizontal (x)-axis
* a vertical (y)-axis

Conceptually:

```text
                 +y
                  ↑
                  |
                  |
                  |
-x  ←-------------+-------------→ +x
                  |
                  |
                  |
                  ↓
                 -y
```

The point where both axes meet is:

[
(0,0)
]

called the **origin**.

---

# 19. Coordinates

A point is written:

[
(x,y)
]

For example:

[
(4,11)
]

means:

[
x=4
]

and:

[
y=11
]

The first value always belongs to the horizontal axis.

The second belongs to the vertical axis.

A useful AI interpretation is:

[
\boxed{(x,y)=(\text{input},\text{output})}
]

---

# 20. Turning a Function into Points

Take:

[
y=2x+3
]

If:

[
x=0
]

then:

[
y=3
]

giving:

[
(0,3)
]

If:

[
x=1
]

then:

[
y=5
]

giving:

[
(1,5)
]

If:

[
x=2
]

then:

[
y=7
]

giving:

[
(2,7)
]

If:

[
x=3
]

then:

[
y=9
]

giving:

[
(3,9)
]

So the equation generates many input-output pairs.

When these points are plotted, they form a straight line.

---

# 21. What a Graph Really Shows

A graph shows:

> How the output behaves when the input changes.

That is much more important than simply knowing how to plot points.

For:

[
y=2x+3
]

as (x) increases:

[
y
]

also increases.

The graph therefore rises.

So visually we can immediately recognize:

[
x\uparrow\Rightarrow y\uparrow
]

---

# 22. The Concept of Change

Suppose:

[
x:1\rightarrow2
]

Then the change in (x) is:

[
2-1=1
]

Suppose at the same time:

[
y:5\rightarrow7
]

Then:

[
7-5=2
]

So:

[
x
]

changed by 1, while:

[
y
]

changed by 2.

This relationship between changes leads us to **slope**.

---

# 23. Delta

Mathematics often represents change using:

[
\Delta
]

pronounced:

> delta

So:

[
\Delta x
]

means:

> change in (x)

and:

[
\Delta y
]

means:

> change in (y)

For example:

[
x:2\rightarrow7
]

means:

[
\Delta x=7-2=5
]

---

# 24. What Is Slope?

Slope tells us:

> How much does the output change relative to a change in the input?

The formula is:

[
\boxed{
m=
\frac{\Delta y}{\Delta x}
}
]

Read this as:

> change in (y), divided by change in (x)

or:

> output change per unit of input change.

---

# 25. Why Do We Divide?

Suppose:

[
x
]

changes by:

[
5
]

while:

[
y
]

changes by:

[
10
]

Then:

[
\frac{10}{5}=2
]

This tells us:

> For every 1 unit of (x)-change, there were 2 units of (y)-change.

So division turns the total change into a **per-unit rate**.

Therefore:

[
\boxed{\text{Slope is a rate of change}}
]

---

# 26. A Real Engineering Interpretation of Slope

Suppose:

[
x=\text{time in seconds}
]

and:

[
y=\text{data downloaded in MB}
]

At 2 seconds:

[
y=100
]

At 5 seconds:

[
y=250
]

Change in time:

[
\Delta x=5-2=3
]

Change in data:

[
\Delta y=250-100=150
]

Therefore:

[
\text{slope}
============

# \frac{150}{3}

50
]

The slope represents:

[
50\text{ MB/s}
]

So slope tells us how quickly one quantity changes relative to another.

---

# 27. Positive Slope

Consider:

[
y=3x
]

Every increase of:

[
1
]

in (x) causes an increase of:

[
3
]

in (y).

Therefore:

[
m=3
]

The line rises.

Conceptually:

```text
y
↑
|        /
|      /
|    /
|  /
|/
+------------→ x
```

A positive slope means:

[
\boxed{x\uparrow\Rightarrow y\uparrow}
]

---

# 28. Negative Slope

Consider:

[
y=-3x
]

Every:

[
+1
]

in (x) causes:

[
-3
]

in (y).

So:

[
m=-3
]

The line falls:

```text
y
↑
|\
| \
|  \
|   \
|    \
+------------→ x
```

A negative slope means:

[
\boxed{x\uparrow\Rightarrow y\downarrow}
]

The negative sign tells us the direction of change.

---

# 29. Zero Slope

Consider:

[
y=5
]

No matter what value (x) takes:

[
y
]

remains 5.

Therefore:

[
\Delta y=0
]

and:

[
m=0
]

Graphically:

```text
y
↑
|
|----------------
|
|
+------------→ x
```

So:

[
\boxed{\text{slope }0=\text{output is not changing}}
]

This becomes extremely important later in optimization.

---

# 30. Slope and Steepness

Compare:

[
y=x
]

and:

[
y=5x
]

For:

[
y=x
]

every (+1) in (x) produces:

[
+1
]

in (y).

For:

[
y=5x
]

every (+1) in (x) produces:

[
+5
]

in (y).

The second line is therefore steeper.

So:

[
\boxed{\text{larger slope magnitude}=\text{stronger response}}
]

---

# 31. Slope as Sensitivity

This interpretation is particularly useful for AI.

Suppose:

[
y=100x
]

A tiny increase in (x) produces a much larger change in (y).

So (y) is highly sensitive to (x).

Now:

[
y=0.01x
]

A large change in (x) produces only a small change in (y).

So the output is much less sensitive.

Therefore slope answers:

> How sensitive is the output to changes in the input?

This is one of the most important bridges toward calculus.

---

# 32. The Straight-Line Equation

A straight line is commonly represented as:

[
\boxed{y=mx+b}
]

where:

[
m=\text{slope}
]

and:

[
b=\text{y-intercept}
]

These two values control different properties of the line.

---

# 33. What Does the Intercept Mean?

Take:

[
y=2x+3
]

Set:

[
x=0
]

Then:

[
y=2(0)+3
]

giving:

[
y=3
]

So the graph passes through:

[
(0,3)
]

The value:

[
3
]

is called the **y-intercept**.

In general:

[
y=mx+b
]

When:

[
x=0
]

we get:

[
y=b
]

Therefore:

[
\boxed{b=\text{output when }x=0}
]

---

# 34. Intercept as a Baseline

A useful interpretation is:

[
\boxed{\text{Intercept = baseline output}}
]

Suppose a cloud provider charges:

* ₹500 fixed monthly fee
* ₹20 for every compute-hour

Let:

[
x=\text{compute hours}
]

and:

[
y=\text{total cost}
]

Then:

[
y=20x+500
]

The slope:

[
20
]

means:

> Every additional compute-hour increases cost by ₹20.

The intercept:

[
500
]

means:

> Even at zero compute-hours, ₹500 remains.

So the intercept represents a baseline contribution independent of (x).

---

# 35. Same Slope, Different Intercepts

Compare:

[
y=2x
]

and:

[
y=2x+5
]

Both have slope:

[
2
]

Therefore they change at the same rate.

But their intercepts are different.

The first crosses at:

[
0
]

The second crosses at:

[
5
]

So changing the intercept moves the line vertically without changing its steepness.

---

# 36. Same Intercept, Different Slopes

Now compare:

[
y=2x+4
]

and:

[
y=5x+4
]

Both have intercept:

[
4
]

But the slopes are different:

[
2
]

and:

[
5
]

The second line changes more rapidly.

Therefore:

[
\boxed{\text{slope changes steepness}}
]

while:

[
\boxed{\text{intercept changes vertical position}}
]

---

# 37. Returning to the AI Equation

Now consider:

[
\boxed{z=wx+b}
]

Compare it with:

[
y=mx+b
]

The structure is the same.

In this simple one-input case:

[
w
]

plays the role of slope.

And:

[
b
]

plays the role of intercept.

This gives us a geometric interpretation of the weight and bias.

---

# 38. (x) — Input

In:

[
z=wx+b
]

the value:

[
x
]

is the input.

It represents information entering the computation.

For example, (x) could represent:

* one measured feature
* a normalized value
* an activation from an earlier layer
* some numerical representation of data

For now, the key idea is:

[
\boxed{x=\text{information entering the calculation}}
]

---

# 39. (w) — Weight

The weight:

[
w
]

multiplies the input:

[
wx
]

Therefore it controls how strongly changes in (x) affect (z).

Suppose:

[
w=2
]

Then:

[
z=2x+b
]

Every increase of 1 in (x) contributes an increase of 2 to (z).

Now suppose:

[
w=8
]

Then:

[
z=8x+b
]

Every increase of 1 in (x) contributes an increase of 8.

So changing the weight changes the sensitivity of the output.

A useful interpretation is:

[
\boxed{
w=\text{how strongly the output responds to the input}
}
]

for this simple linear case.

---

# 40. Positive Weight

Suppose:

[
w=3
]

Then:

[
z=3x+b
]

As (x) increases, (z) tends to increase.

The input and output move in the same direction.

---

# 41. Negative Weight

Suppose:

[
w=-3
]

Then:

[
z=-3x+b
]

As (x) increases, the weighted contribution decreases.

So the relationship moves in the opposite direction.

This shows why the sign of a weight matters.

A weight doesn't only control:

> how much

It can also influence:

> in which direction.

---

# 42. Small Weight

Suppose:

[
w=0.01
]

Then:

[
z=0.01x+b
]

Changes in (x) have relatively little direct effect on (z).

The relationship is nearly flat.

So the model is relatively insensitive to (x) in this simple setup.

---

# 43. Zero Weight

Suppose:

[
w=0
]

Then:

[
z=0x+b
]

so:

[
z=b
]

The value of (x) no longer affects (z) at all.

That input's direct contribution has effectively disappeared from this linear operation.

This gives us another useful intuition:

[
\boxed{w=0\Rightarrow\text{this input contributes nothing through }wx}
]

---

# 44. (b) — Bias

The bias:

[
b
]

is added independently of (x).

Suppose:

[
z=2x+4
]

When:

[
x=0
]

we get:

[
z=4
]

So the bias creates a baseline.

Now change only the bias:

[
z=2x+10
]

The slope remains:

[
2
]

but every output is shifted upward by 6 compared with the previous relationship.

Thus:

[
\boxed{b=\text{baseline or vertical shift}}
]

in this simple model.

---

# 45. Why Does a Neuron Need Bias?

Suppose we had only:

[
z=wx
]

Then whenever:

[
x=0
]

we are forced to have:

[
z=0
]

regardless of the weight.

The graph must pass through:

[
(0,0)
]

Now add a bias:

[
z=wx+b
]

When:

[
x=0
]

we have:

[
z=b
]

The relationship is no longer forced to pass through zero.

The model gains more flexibility.

So:

[
\boxed{\text{Bias allows the relationship to shift independently of the input}}
]

---

# 46. Weight and Bias Control Different Things

Take:

[
z=2x+4
]

Here:

[
w=2
]

and:

[
b=4
]

Now change only (w):

[
z=5x+4
]

The line becomes steeper.

The intercept remains:

[
4
]

Now return to:

[
z=2x+4
]

and change only (b):

[
z=2x+10
]

The slope remains:

[
2
]

but the line shifts upward.

Therefore:

[
\boxed{w\text{ controls slope}}
]

and:

[
\boxed{b\text{ controls shift/baseline}}
]

---

# 47. Geometric Interpretation

A useful visual intuition is:

[
\boxed{w\text{ changes the tilt of the line}}
]

while:

[
\boxed{b\text{ moves the line up or down}}
]

This is not the complete story for huge multidimensional neural networks, but it is an excellent starting intuition.

---

# 48. A Complete Forward Calculation

Take:

[
z=wx+b
]

Suppose:

[
x=3
]

[
w=2
]

[
b=4
]

First multiply:

[
wx=2\times3=6
]

Then add the bias:

[
6+4=10
]

Therefore:

[
z=10
]

The computation can be viewed as:

[
3
\xrightarrow{\times2}
6
\xrightarrow{+4}
10
]

or:

[
x
\xrightarrow{\times w}
wx
\xrightarrow{+b}
z
]

This is a simple **forward computation**.

---

# 49. What Happens If the Input Changes?

Keep:

[
w=2
]

and:

[
b=4
]

Originally:

[
x=3
]

giving:

[
z=10
]

Now increase:

[
x:3\rightarrow4
]

Then:

[
z=2(4)+4
]

giving:

[
z=12
]

So:

[
\Delta x=1
]

and:

[
\Delta z=2
]

Therefore:

[
\frac{\Delta z}{\Delta x}=2
]

which matches:

[
w=2
]

This demonstrates mathematically why (w) is the slope in this simple relationship.

---

# 50. What Happens If the Weight Changes?

Keep:

[
x=3
]

and:

[
b=4
]

Originally:

[
w=2
]

giving:

[
z=10
]

Now change:

[
w=5
]

Then:

[
z=5(3)+4
]

giving:

[
z=19
]

Nothing about the input changed.

Nothing about the bias changed.

The model's parameter changed.

That caused the output to change.

This observation is extremely important for machine learning.

It means:

[
\boxed{\text{changing parameters changes model behavior}}
]

---

# 51. What Happens If the Bias Changes?

Keep:

[
x=3
]

and:

[
w=2
]

Originally:

[
b=4
]

giving:

[
z=10
]

Now change:

[
b=10
]

Then:

[
z=2(3)+10
]

giving:

[
z=16
]

The slope remains unchanged.

The baseline moved.

Again:

[
\boxed{\text{Changing a parameter changes the output}}
]

---

# 52. The Beginning of Machine Learning

This creates a crucial idea.

Suppose the model produces:

[
z=10
]

but we wanted something closer to:

[
15
]

The output depends on:

[
w
]

and:

[
b
]

So perhaps we can improve the output by changing:

[
w
]

or:

[
b
]

This is the basic idea of **learning**.

A machine-learning system adjusts its parameters to improve its outputs.

Very roughly:

[
\boxed{
\text{bad output}
\rightarrow
\text{adjust parameters}
\rightarrow
\text{better output}
}
]

The difficult question is:

> How do we know which parameter to change, which direction to change it, and by how much?

That question will eventually lead us to loss functions, derivatives, gradients, and optimization.

---

# 53. Why Slope Matters for Learning

Suppose:

[
z=wx+b
]

The weight tells us how sensitive (z) is to (x).

But during training, we eventually need to ask a different kind of sensitivity question:

> How sensitive is the loss to the weight?

That will eventually look like:

[
\frac{\partial L}{\partial w}
]

Do not worry about that notation yet.

The important connection is:

[
\boxed{\text{slope}\rightarrow\text{sensitivity}}
]

We are building the intuition before introducing calculus.

---

# 54. Straight Lines vs Curves

For:

[
y=2x+3
]

the slope is always:

[
2
]

No matter where we are on the line.

But many relationships in AI are curved.

Conceptually:

```text
y
↑
|                  /
|               __/
|            __/
|         __/
|______--/
+----------------------→ x
```

On a curve, the steepness can change from place to place.

That creates a more difficult question:

> What is the slope at this exact location?

That question eventually leads to a **derivative**.

So the path is:

[
\boxed{
\text{change}
\rightarrow
\text{slope}
\rightarrow
\text{sensitivity}
\rightarrow
\text{derivative}
}
]

---

# 55. Why Zero Slope Will Matter Later

Recall:

[
\text{slope}=0
]

means the output isn't changing with respect to the input at that location.

Now imagine a loss curve:

```text
Loss
 ↑
 | \               /
 |  \             /
 |   \           /
 |    \_________/
 |
 +------------------------→ parameter
```

Near the bottom, the curve becomes flat.

Its slope approaches:

[
0
]

That is one reason zero derivatives become important in optimization.

We will study this properly later.

For now, connect:

[
\boxed{\text{flat}\rightarrow\text{little or no change}}
]

# 56. The First Mathematical Picture of a Neuron

A simplified neuron starts with:

[
z=wx+b
]

In a more realistic neuron with several inputs:

[
z=w_1x_1+w_2x_2+w_3x_3+\cdots+b
]

Each input:

[
x_i
]

has its own weight:

[
w_i
]

The neuron:

1. Receives inputs
2. Scales each input by a weight
3. Adds the weighted contributions
4. Adds a bias
5. Produces (z)

So:

[
\boxed{
z=
\text{weighted inputs}
+
\text{bias}
}
]

Later, (z) is usually passed through another function called an **activation function**.

But that belongs to a later lesson.

---

# 57. From One Input to Many Inputs

Our simple equation:

[
z=wx+b
]

contains one input.

A more realistic version is:

[
z=w_1x_1+w_2x_2+b
]

Suppose:

[
x_1=3
]

[
x_2=5
]

[
w_1=2
]

[
w_2=0.5
]

[
b=1
]

Then:

[
z=(2)(3)+(0.5)(5)+1
]

So:

[
z=6+2.5+1
]

giving:

[
z=9.5
]

The important part is not the arithmetic.

It is the structure:

[
x_1
\xrightarrow{\times w_1}
w_1x_1
]

and:

[
x_2
\xrightarrow{\times w_2}
w_2x_2
]

Then:

[
w_1x_1+w_2x_2
]

Then:

[
+b
]

Then:

[
z
]

---

# 58. Why Different Inputs Have Different Weights

Suppose a model receives two pieces of information.

It may need one input to influence the result strongly and another only slightly.

Using different weights gives the model this ability.

If:

[
w_1=5
]

and:

[
w_2=0.1
]

then, assuming comparable scales, changes in:

[
x_1
]

have a much stronger direct influence than comparable changes in:

[
x_2
]

This is one way neural networks can learn complex relationships between inputs.

---

# 59. Parameters Are the Things Training Learns

In:

[
z=w_1x_1+w_2x_2+b
]

the inputs:

[
x_1,x_2
]

come from data or previous computations.

The values:

[
w_1,w_2,b
]

are parameters.

Training changes the parameters.

So:

[
\boxed{
\text{Inputs carry information}
}
]

while:

[
\boxed{
\text{Parameters determine how that information is transformed}
}
]

This distinction is central to machine learning.

Everything we studied today can be connected into one sequence.

Start with a variable:

[
x
]

Use it in an expression:

[
wx+b

Name the result with an equation:

[
z=wx+b
]

Interpret it as a function:

[
x
\rightarrow
wx+b
\rightarrow
z

Represent that relationship with a graph.

\boxed{
x
\rightarrow
\text{weight}

\text{scaled contribution}

]

# Day 4 — Core Ideas to Remember

## Variables represent quantities

[
x
]

is simply a name for a value that can vary.

---

## Expressions perform calculations

[
wx+b
]

describes a computation.

---

## Equations describe relationships

[
z=wx+b
]

says the result of that computation is called (z).

---

## Functions transform inputs into outputs

[
f(x)
]

means:

> Give (x) to function (f).

The basic pattern is:

[
\boxed{\text{input}\rightarrow\text{transformation}\rightarrow\text{output}}
]

---

## Graphs visualize relationships

An equation and its graph describe the same underlying behavior in different forms.

---

## Delta means change

[
\Delta x
]

means:

> change in (x)

---

## Slope measures rate of change

[
m=
\frac{\Delta y}{\Delta x}
]

means:

> how much output changes per unit input change.

---

## Slope also represents sensitivity

A large slope magnitude means the output responds strongly to the input.

A small slope magnitude means it responds weakly.

---

## Positive slope

[
x\uparrow\Rightarrow y\uparrow
]

---

## Negative slope

[
x\uparrow\Rightarrow y\downarrow
]

---

## Zero slope

The output is not changing with respect to the input.

---

## The straight-line equation

[
y=mx+b
]

contains:

[
m=\text{slope}
]

and:

[
b=\text{intercept}
]

---

## Intercept means baseline

[
b
]

is the value of the output when:

[
x=0
]

---

## Neural-network connection

Our simplified neuron is:

[
\boxed{z=wx+b}
]

where:

[
x=\text{input}
]

[
w=\text{weight}
]

[
b=\text{bias}
]

[
z=\text{result}
]

---

## Weight behaves like slope

For the simple linear relationship:

[
z=wx+b
]

the weight tells us how much (z) changes when (x) changes.

So:

[
\boxed{w=\text{sensitivity of }z\text{ to }x}
]

in this simple case.

---

## Bias behaves like an intercept

The bias controls the baseline:

[
x=0\Rightarrow z=b
]

So:

[
\boxed{b=\text{baseline/shift}}
]

---

## Training changes parameters

Changing:

[
w
]

or:

[
b
]

changes the model's output.

Therefore machine learning can improve behavior by learning better parameter values.

# Day 4 Mental Model

When you see:

[
\boxed{z=wx+b}
]

you should be able to mentally translate it as:

> Take input (x).

> Multiply it by weight (w), which controls how strongly that input influences the result.

> Add bias (b), which provides an independent baseline or shift.

> Call the resulting value (z).

Graphically, in the simple one-input case:

> (w) controls the line's steepness and direction.

> (b) controls where the line sits vertically.

And from a machine-learning perspective:

> (w) and (b) are parameters that training can change.

That gives us the larger chain:

[
\boxed{
\text{input}
\rightarrow
\text{parameter-controlled transformation}
\rightarrow
\text{output}
}
]

Later, training will compare that output against what the model should have produced.

Then we will ask:

> How wrong was the model?

> Which parameters contributed to that error?

> Which direction should each parameter move?

> How much should each parameter move?

Those questions eventually lead to:

[
\text{loss}
\rightarrow
\text{derivatives}
\rightarrow
\text{gradients}
\rightarrow
\text{gradient descent}
\rightarrow
\text{backpropagation}
]

But Day 4 gives us the mathematical foundation we need before going there.
