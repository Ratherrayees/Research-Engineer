# 2. Equations and Graphs Describe the Same Relationship

Consider:

[
y=2x+3
]

This equation describes a relationship between:

[
x
]

and:

[
y
]

Instead of only calculating individual values, we can draw all possible input-output relationships on a graph.

So:

[
\boxed{\text{Equation}\leftrightarrow\text{Graph}}
]

They are not two unrelated topics.

They are two ways of representing the same relationship.

An equation expresses the relationship using symbols.

A graph expresses it visually.

---

# 3. The Coordinate Plane

A basic two-dimensional graph contains two number lines.

The horizontal line is called the:

[
x\text{-axis}
]

The vertical line is called the:

[
y\text{-axis}
]

Conceptually:

```text
                 +y
                  ↑
                  |
                  |
                  |
-x  ←-------------+-------------→ +x
                  |
                  |
                  |
                  ↓
                 -y
```

The two axes intersect at:

[
(0,0)
]

This point is called the **origin**.

---

# 4. Why We Need Two Axes

Suppose we want to describe the relationship:

[
y=2x
]

We need to represent both:

* the input (x)
* the resulting output (y)

So we use one axis for each quantity.

Horizontal:

[
x
]

Vertical:

[
y
]

This allows us to represent one input-output pair as a single position on the graph.

---

# 5. Coordinates

A point on a graph is usually written as:

[
(x,y)
]

For example:

[
(3,5)
]

means:

[
x=3
]

and:

[
y=5
]

The order matters.

Always:

[
\boxed{(x,y)}
]

not:

[
(y,x)
]

So for:

[
(3,5)
]

we move:

* 3 units horizontally
* 5 units vertically

and mark that location.

---

# 6. Coordinates as Input-Output Pairs

For AI and functions, there is a particularly useful way to think about coordinates.

Instead of seeing:

[
(x,y)
]

as just two random numbers, think:

[
\boxed{(\text{input},\text{output})}
]

For example:

[
(3,7)
]

might mean:

> Input (x=3) produced output (y=7).

This connects graphs directly to functions.

---

[

y=2(0)+1

[
y=1

[
(0,1)
]

[
x=1
]

Then:

[

]

giving:

[
(1,3)
]

Now:

[

]

gives:

[

]

so:

[

[

so:

We now have:

[
(0,1),(1,3),(2,5),(3,7)

These points all belong to the same function.

# 8. Why Those Points Form a Line

Consider again:

[
y=2x+1
]

Every time (x) increases by:

[
1
]

the value of (y) increases by:

[
2
]

The rate of change remains constant.

Therefore, when we plot all the points, they form a straight line.

This type of relationship is called **linear**.

The important idea is:

[
\boxed{\text{constant rate of change}\rightarrow\text{straight-line relationship}}
]

We will study this more carefully later.

---

# 9. What a Graph Actually Shows

A graph is not merely a picture of some numbers.

It shows:

> **How one quantity behaves as another quantity changes.**

Suppose:

[
x=\text{time}
]

and:

[
y=\text{amount of data processed}
]

A graph could show whether processing is:

* increasing steadily
* slowing down
* accelerating
* remaining constant
* decreasing

The overall shape reveals the behavior of the relationship.

This is one reason graphs are so useful in AI and engineering.

---

# 10. Reading Direction on a Graph

Imagine a graph that rises as we move from left to right.

Conceptually:

```text
y
↑
|          /
|        /
|      /
|    /
|  /
+----------------→ x
```

As:

[
x\uparrow
]

we also have:

[
y\uparrow
]

So:

[
\boxed{x\uparrow\Rightarrow y\uparrow}
]

The quantities move in the same general direction.

---

# 11. Decreasing Relationships

Now consider:

```text
y
↑
|\
| \
|  \
|   \
|    \
+----------------→ x
```

As:

[
x\uparrow
]

we have:

[
y\downarrow
]

So:

[
\boxed{x\uparrow\Rightarrow y\downarrow}
]

The quantities move in opposite directions.

The sign of the slope will later capture this difference mathematically.

---

# 12. Flat Relationships

Consider:

```text
y
↑
|
|----------------------
|
|
+--------------------→ x
```

Here, (x) changes but (y) does not.

So:

[
x\uparrow
]

while:

[
y=\text{constant}
]

The rate of change is therefore zero.

Later, we will express this as:

[
\text{slope}=0
]

This idea becomes extremely important in optimization.

# 13. Positive and Negative Coordinates

Both axes contain positive and negative values.

So points can exist in different regions of the graph.

For example:

[
(3,5)
]

means:

* positive (x)
* positive (y)

While:

[
(-3,5)
]

means:

* negative (x)
* positive (y)

And:

[
(3,-5)
]

means:

* positive (x)
* negative (y)

And:

[
(-3,-5)
]

means both are negative.

The graph is commonly divided into four regions called **quadrants**.

You do not need to memorize the quadrant numbering yet.

What matters is becoming comfortable with movement in positive and negative directions.

---

# 14. Why Negative Values Matter in AI

Neural-network values are not restricted to positive numbers.

Weights, activations, intermediate values, gradients, logits, and other quantities can often be negative.

So mathematically, we need a coordinate system capable of describing movement in either direction.

This becomes especially important when we discuss optimization.

A parameter might need to:

[
\text{increase}
]

or:

[
\text{decrease}
]

depending on what reduces the model's loss.

---

# 15. Linear Relationships

A simple linear relationship can often be written:

[
y=mx+b
]

Here:

[
m
]

controls how quickly (y) changes as (x) changes.

And:

[
b
]

controls where the line crosses the (y)-axis.

We will study both carefully.

But first, let's understand what "linear" means.

A linear relationship has a **constant slope**.

If changing (x) by 1 always changes (y) by the same amount, the graph forms a straight line.

For example:

[
y=3x
]

gives:

[
x=1\Rightarrow y=3
]

[
x=2\Rightarrow y=6
]

[
x=3\Rightarrow y=9
]

[
x=4\Rightarrow y=12
]

Every:

[
+1
]

in (x) produces:

[
+3
]

in (y).

That constant change produces a straight line.

---

# 16. What Is Change?

Before slope, we need one simple concept:

[
\boxed{\text{change}=\text{new value}-\text{old value}}
]

Suppose (x) moves from:

[
3
]

to:

[
8
]

Then the change is:

[
8-3=5
]

So:

[
\text{change in }x=5
]

If (x) moves from:

[
8
]

to:

[
3
]

then:

[
3-8=-5
]

So the change is:

[
-5
]

The negative sign tells us the movement went downward.

---

# 17. Delta — The Symbol for Change

Mathematics commonly uses the Greek letter:

[
\Delta
]

pronounced:

> Delta

to mean:

> Change in

So:

[
\Delta x
]

means:

> change in (x)

And:

[
\Delta y
]

means:

> change in (y)

Suppose:

[
x:2\rightarrow7
]

Then:

[
\Delta x=7-2=5
]

Suppose:

[
y:10\rightarrow20
]

Then:

[
\Delta y=20-10=10
]

Therefore:

[
\Delta x=5
]

and:

[
\Delta y=10
]

This notation will appear constantly later.

---

# 18. Rate of Change

Suppose (x) changes by:

[
5
]

while (y) changes by:

[
10
]

We want to know:

> How much did (y) change relative to the change in (x)?

We calculate:

[
\frac{\Delta y}{\Delta x}
]

So:

[
\frac{10}{5}=2
]

This means:

> For every 1 unit of change in (x), (y) changed by 2 units.

This is called a **rate of change**.

---

# 19. Why We Divide Changes

Suppose two systems are being compared.

System A:

[
x\text{ changes by }2
]

and:

[
y\text{ changes by }6
]

System B:

[
x\text{ changes by }10
]

and:

[
y\text{ changes by }30
]

At first the (y)-changes look different:

[
6
]

versus:

[
30
]

But calculate the rate.

System A:

[
\frac{6}{2}=3
]

System B:

[
\frac{30}{10}=3
]

Both relationships change at the same rate.

So division lets us normalize the change and ask:

> How much (y)-change happens **per unit of (x)-change**?

---

# 20. Slope

For a straight line, this rate of change is called the **slope**.

The basic slope formula is:

[
\boxed{
\text{slope}
============

\frac{\text{change in }y}
{\text{change in }x}
}
]

Using delta notation:

[
\boxed{
m=\frac{\Delta y}{\Delta x}
}
]

where:

[
m=\text{slope}
]

Do not memorize the formula as random notation.

Read it:

> Slope tells us how much the output changes per unit of input change.

---

# 21. Calculating Slope from Two Points

Suppose we have two points:

[
(2,5)
]

and:

[
(5,11)
]

First calculate the change in (x):

[
\Delta x=5-2=3
]

Now calculate the change in (y):

[
\Delta y=11-5=6
]

Therefore:

[
m=\frac{6}{3}=2
]

So the slope is:

[
2
]

Meaning:

> Every increase of 1 in (x) corresponds to an increase of 2 in (y).

---

# 22. The Full Two-Point Slope Formula

If our two points are:

[
(x_1,y_1)
]

and:

[
(x_2,y_2)
]

then:

[
\Delta y=y_2-y_1
]

and:

[
\Delta x=x_2-x_1
]

Therefore:

[
\boxed{
m=
\frac{y_2-y_1}
{x_2-x_1}
}
]

Again, don't memorize this blindly.

It simply means:

[
\frac{\text{new }y-\text{old }y}
{\text{new }x-\text{old }x}
]

which is:

[
\frac{\text{change in output}}
{\text{change in input}}
]

---

# 23. Positive Slope

Consider:

[
y=2x
]

If (x) increases by 1:

[
y
]

increases by 2.

Therefore:

[
m=2
]

The slope is positive.

Graphically:

```text
y
↑
|        /
|      /
|    /
|  /
|/
+------------→ x
```

Positive slope means:

[
\boxed{x\uparrow\Rightarrow y\uparrow}
]

# 24. Negative Slope

Consider:

[
y=-2x
]

When (x) increases by:

[
1
]

(y) decreases by:

[
2
]

So:

[
m=-2
]

Graphically:

```text
y
↑
|\

|  \

|    \

```

Negative slope means:

\boxed{x\uparrow\Rightarrow y\downarrow}

# 25. Zero Slope

Consider:

[
y=5
]

No matter what (x) becomes:

[
y=5
]

Suppose:

[
x:2\rightarrow10
]

Then:

[
\Delta x=8
]

But:

[
\Delta y=0
]

Therefore:

[
m=\frac{0}{8}=0
]

The slope is zero.

Graphically:

```text
y
↑
|
|-------------------
|
|
+----------------→ x
```

A zero slope means:

[
\boxed{\text{The output is not changing as the input changes}}
]

This statement will become extremely important when we study minima and optimization.

---

# 26. Steepness

The magnitude of the slope tells us how quickly (y) changes.

Compare:

[
y=x
]

with:

[
y=5x
]

For:

[
y=x
]

an increase of 1 in (x) produces an increase of 1 in (y).

For:

[
y=5x
]

an increase of 1 in (x) produces an increase of 5 in (y).

Therefore:

[
y=5x
]

has a steeper line.

So:

[
\boxed{\text{larger slope magnitude}\rightarrow\text{greater sensitivity}}
]

---

# 27. Slope as Sensitivity

The word **sensitivity** is particularly important for AI.

Suppose:

[
y=100x
]

A small change in (x) causes a much larger change in (y).

The output is highly sensitive to the input.

Now consider:

[
y=0.01x
]

A change in (x) produces only a tiny change in (y).

The output is much less sensitive.

So slope tells us something deeper than how steep a line looks.

It tells us:

> How strongly does the output respond to changes in the input?

This is one of the conceptual bridges toward derivatives.

---

# 28. The Equation of a Straight Line

A very common form is:

[
\boxed{y=mx+b}
]

where:

[
m=\text{slope}
]

and:

[
b=\text{y-intercept}
]

The equation therefore contains two different controls:

[
m
]

controls how quickly the output changes.

[
b
]

controls where the line is positioned vertically.

---

# 29. Understanding the Slope Term (m)

Consider:

[
y=3x+5
]

The slope is:

[
m=3
]

So every:

[
+1
]

change in (x) produces:

[
+3
]

change in (y).

Now:

[
y=-4x+5
]

has slope:

[

]

So every:

[
+1
]

in (x) produces:

[
-4
]

in (y).

The slope controls the line's direction and steepness.

# 30. The Y-Intercept

Consider:

[
y=2x+3
]

What happens when:

[
x=0
]

?

Substitute:

[
y=2(0)+3
]

giving:

[
y=3
]

Therefore the line passes through:

[
(0,3)
]

The value:

[
3
]

is the **y-intercept**.

More generally, in:

[

]

[

[

[
\boxed{b=\text{value of }y\text{ when }x=0}

# 31. Intercept as a Baseline

A useful way to think about the intercept is:

[
\boxed{\text{intercept = baseline output}}
]

Suppose a cloud service charges:

* ₹500 base fee
* ₹20 per compute-hour

Let:

[
x=\text{compute hours}
]

and:

[
y=\text{total cost}
]

Then:

[
y=20x+500
]

The:

[
20
]

is the slope.

It means every additional compute-hour adds ₹20.

The:

[
500
]

is the intercept.

Even when:

[
x=0
]

the cost is:

[
₹500
]

So the intercept represents a baseline independent of usage.

# 32. Same Slope, Different Intercepts

Compare:

[
y=2x
]

and:

[
y=2x+5
]

Both have slope:

[
2
]

Therefore both change at exactly the same rate.

But one has intercept:

[
0
]

and the other:

[
5
]

So the lines are parallel but vertically shifted.

Conceptually:

```text
y
↑
|          /   y = 2x + 5
|        /
|      /
|    /      y = 2x
|  /
|/
+----------------→ x
```

# 33. Slope vs Intercept

In:

[
y=mx+b
]

remember:

[
\boxed{m=\text{rate of change}}
]

and:

[
\boxed{b=\text{baseline}}
]

These roles are different.

For:

[
y=4x+100
]

the `4` determines how rapidly the output changes.

The `100` determines the starting vertical position.

Even though 100 is numerically larger than 4, it does not mean it has the larger effect on slope.

Numbers have meaning based on the role they play in the equation.

# 34. Connection to Neural Networks

Now return to our familiar equation:

[

Compare it with:

[

In the simple one-input case:

[

[

Suppose:

[
z=2x+4
]

Then:

[

]

The output changes by 2 for every unit change in (x).

Now change the weight:

[
z=7x+4
]

The intercept remains the same:

[
4
]

but the line becomes much steeper.

Therefore changing the weight changes:

> how strongly the output responds to changes in the input.

So, for this simple linear case:

[
\boxed{

\text{sensitivity of output to input}
}
]

This interpretation becomes extremely useful later.

[

]

# 38. Graphs and Loss Functions

Graphs become especially important when we begin training models.

Suppose:

[
x=\text{value of a model parameter}
]

and:

[
y=\text{loss}
]

We might obtain a relationship roughly shaped like:

```text
Loss
 ↑
 |  \               /
 |   \             /
 |    \           /
 |     \_________/
 |
 +------------------------→ parameter value
```

The bottom region represents lower loss.

Training wants to find parameter values that produce lower loss.

This immediately introduces questions such as:

> Which direction should the parameter move?

> How steeply is the loss changing?

> Are we near a flat region?

These questions will eventually be answered using derivatives and gradients.

---

# 39. Why Slope Leads to Calculus

For a straight line:

[
y=2x+3
]

the slope is always:

[
2
]

No matter where we measure it.

But many AI relationships are not straight lines.

They may look like:

```text
y
↑
|             __
|          __/
|       __/
|    __/
|___/
+----------------→ x
```

Now the steepness changes depending on where we are.

So asking:

[
\frac{\Delta y}{\Delta x}
]

over a large interval may not tell us the exact slope at one specific location.

That creates a new problem:

> What is the slope **right here**, at one particular point on a curve?

Solving that problem leads to:

[
\boxed{\text{derivatives}}
]

So slope is not an isolated school topic.

It is the doorway into calculus.

---

# 40. Average Rate of Change vs Instantaneous Rate of Change

Suppose we compare two points on a curve.

We calculate:

[
\frac{\Delta y}{\Delta x}
]

That tells us the **average rate of change** between those two points.

But if the curve changes steepness, the slope at a particular point might be different.

Eventually we will shrink:

[
\Delta x
]

smaller and smaller.

As the distance approaches zero, we can measure the rate of change at essentially one point.

That becomes the derivative.

You do not need the calculus yet.

For now, remember:

[
\boxed{\text{slope between points}\rightarrow\text{average change}}
]

while later:

[
\boxed{\text{derivative at a point}\rightarrow\text{instantaneous change}}
]

---

# 41. Why This Matters for Model Training

Suppose a model parameter is:

[
w
]

and the loss is:

[
L
]

We can imagine a graph:

[
w\rightarrow L
]

At the model's current (w), we want to know:

> If I increase (w) slightly, does the loss increase or decrease?

And:

> How strongly does the loss respond?

That is essentially a slope question.

Eventually we will represent it as:

[
\frac{dL}{dw}
]

Read conceptually as:

> How sensitive is the loss to a change in this weight?

So everything we are learning about graphs and slope is building directly toward neural-network training.

Recall Day 2:

[

The relationship could:

* increase rapidly

# 43. Linear vs Nonlinear Relationships

A straight-line relationship is linear:

```text
y
↑
|       /
|      /
|     /
|    /
|___/____________→ x
```

Its slope stays constant.

A nonlinear relationship might look like:

```text
y
↑
|             /
|          __/
|       __/
|    __/
|___/
+----------------→ x
```

Its slope changes from place to place.

Neural networks rely heavily on nonlinear relationships.

Without nonlinearity, stacking many linear transformations would still collapse into another linear transformation.

We will explore why when we study activation functions.

For Day 3, simply understand:

[
\boxed{\text{linear = constant slope}}
]

[
\boxed{\text{nonlinear = slope can change}}
]

}
]

That progression is extremely important.

# Day 3 — Core Ideas to Remember

## Graphs visualize relationships

An equation:

[
y=f(x)
]

and its graph represent the same underlying relationship.

---

## Coordinates represent input-output pairs

[
(x,y)
]

can be understood as:

[
(\text{input},\text{output})
]

---

## Change means new minus old

[
\Delta x=x_{\text{new}}-x_{\text{old}}
]

---

## Delta means change

[
\Delta x
]

means:

> change in (x)

---

## Rate of change compares changes

[
\frac{\Delta y}{\Delta x}
]

means:

> how much (y) changes per unit change in (x)

---

## Slope is rate of change for a line

[
m=\frac{\Delta y}{\Delta x}
]

---

## Positive slope

[
x\uparrow\Rightarrow y\uparrow
]

---

## Negative slope

[
x\uparrow\Rightarrow y\downarrow
]

---

## Zero slope

[
x\text{ changes while }y\text{ does not}
]

---

## Slope magnitude describes sensitivity

A steeper relationship means the output responds more strongly to changes in the input.

---

## Straight-line equation

[
y=mx+b
]

where:

[
m=\text{slope}
]

and:

[
b=\text{intercept}
]

---

## Intercept is the baseline

When:

[
x=0
]

then:

[
y=b
]

---

## Neural-network connection

In the simple relationship:

[
z=wx+b
]

the weight (w) plays the mathematical role of slope.

The bias (b) plays the mathematical role of the intercept.

---

# Day 3 Mental Model

The most important idea from Day 3 is:

[
\boxed{\text{Slope tells us how sensitive one quantity is to another}}
]

If:

[
y=5x
]

then:

[
x+1\Rightarrow y+5
]

The output is quite sensitive to changes in the input.

If:

[
y=0.01x
]

then:

[
x+1\Rightarrow y+0.01
]

The output responds much less.

Eventually neural-network training will ask:

> How sensitive is the loss to this particular parameter?

That question will become:

[
\frac{\partial L}{\partial w}
]

But when we reach that notation, it should no longer feel like an arbitrary formula.

You should recognize the underlying question:

> **If I change this parameter a little, how does the loss respond?**

That is the bridge from basic algebra and graphs into calculus and model learning.
