# Tensors & Data — Day 1

## Scalars, Vectors, Matrices, Tensors, Shape, and Axes

---

## 1. Why This Topic Matters

AI systems do not work with isolated numbers for very long.

Very quickly, data becomes groups of numbers:

- one value,
- a list of values,
- rows and columns,
- batches of samples,
- sequences of tokens,
- embeddings,
- activations,
- model parameters.

To reason about all of this, I need to understand how numerical data is structured.

The first mental model is:

```text
single number
→ scalar

ordered 1D values
→ vector

rows × columns
→ matrix

higher-dimensional numerical structure
→ tensor
```

The important idea is not just the numbers themselves.

> The structure of the numbers matters.

---

## 2. Python Lists vs Numerical Arrays

A Python list can hold values:

```python
values = [1, 2, 3, 4]
```

But a normal Python list is a general-purpose container.

It is not primarily designed for fast numerical computation.

A NumPy array is designed for numerical work:

```python
import numpy as np

# Store several numerical values in one NumPy array.
x = np.array([1, 2, 3, 4])

# NumPy performs numerical multiplication element by element.
print(x * 2)
# [2 4 6 8]
```

A normal Python list behaves differently:

```python
values = [1, 2, 3, 4]

# This repeats the list rather than multiplying each number.
print(values * 2)
# [1, 2, 3, 4, 1, 2, 3, 4]
```

This is one reason numerical libraries are important in AI.

They let us operate on many values together.

---

## 3. Scalar

A scalar is one numerical value.

Examples:

```text
5
0.01
-3.2
```

In AI, scalars can represent things such as:

- one learning rate,
- one loss value,
- one model parameter,
- one probability,
- one temperature value.

With NumPy:

```python
import numpy as np

# A zero-dimensional NumPy array containing one number.
scalar = np.array(5.0)

print(scalar)
print(scalar.shape)  # ()
print(scalar.ndim)   # 0
```

The empty shape `()` means there are no axes around the value.

---

## 4. Vector

A vector is a one-dimensional ordered collection of values.

Example:

```text
[2.1, -0.4, 7.3]
```

With NumPy:

```python
import numpy as np

# One vector containing three numerical components.
x = np.array([2.1, -0.4, 7.3])

print(x.shape)  # (3,)
print(x.ndim)   # 1
```

The shape `(3,)` means:

```text
one axis
containing 3 values
```

A vector may represent:

- several features of one sample,
- several weights,
- one embedding,
- one row of a dataset.

Important distinction:

A vector containing 100 values is still 1D.

```text
number of values != number of axes
```

---

## 5. Matrix

A matrix is a two-dimensional numerical structure.

Example:

```text
[
  [1, 2, 3],
  [4, 5, 6]
]
```

With NumPy:

```python
import numpy as np

matrix = np.array([
    [1, 2, 3],
    [4, 5, 6]
])

print(matrix.shape)  # (2, 3)
print(matrix.ndim)   # 2
```

Shape:

```text
(2, 3)
```

means:

```text
2 rows
3 columns
```

A matrix can represent:

- multiple samples with multiple features,
- neural-network weights,
- embedding tables,
- many vectors collected together.

---

## 6. Tensor

In AI engineering, the word **tensor** usually refers to a multidimensional numerical array used for computation.

A useful programming mental model is:

```text
0D → scalar
1D → vector
2D → matrix
3D+ → higher-dimensional tensor
```

Example of a 3D tensor:

```python
import numpy as np

x = np.array([
    [
        [1, 2],
        [3, 4]
    ],
    [
        [5, 6],
        [7, 8]
    ]
])

print(x.shape)  # (2, 2, 2)
print(x.ndim)   # 3
```

The numbers in the shape describe the size of each axis.

---

## 7. Shape

Shape tells us how many positions exist along each axis.

For this matrix:

```python
x = np.array([
    [1, 2, 3],
    [4, 5, 6]
])
```

we get:

```python
print(x.shape)
# (2, 3)
```

Meaning:

```text
axis 0 has size 2
axis 1 has size 3
```

For AI work, shape is one of the first things I should inspect when something does not make sense.

A useful habit:

> Predict the shape first. Run the code second.

---

## 8. Number of Axes — `ndim`

`ndim` tells us how many axes exist.

```python
import numpy as np

scalar = np.array(5)
vector = np.array([1, 2, 3])
matrix = np.array([[1, 2], [3, 4]])

print(scalar.ndim)  # 0
print(vector.ndim)  # 1
print(matrix.ndim)  # 2
```

This is different from the number of values.

Example:

```text
[1, 2, 3, 4, 5, 6]
```

contains six values but still has only one axis.

---

## 9. Axis

An axis is one direction through a tensor.

For a matrix shaped:

```text
(2, 3)
```

we can think of:

```text
axis 0 → moves between rows
axis 1 → moves across columns
```

Example:

```python
import numpy as np

x = np.array([
    [10, 20, 30],
    [40, 50, 60]
])

# Mean across axis 0 combines values from different rows
# at the same column positions.
print(np.mean(x, axis=0))
# [25. 35. 45.]

# Mean across axis 1 combines values inside each row.
print(np.mean(x, axis=1))
# [20. 50.]
```

This matters later for:

- batch loss,
- normalization,
- softmax,
- attention,
- feature aggregation.

---

## 10. Shape vs `ndim` vs Size

These three ideas describe different things.

For:

```python
x = np.zeros((2, 3, 4))
```

we get:

```python
print(x.shape)  # (2, 3, 4)
print(x.ndim)   # 3
print(x.size)   # 24
```

Meaning:

```text
shape → size of every axis
ndim  → number of axes
size  → total number of elements
```

Since:

```text
2 × 3 × 4 = 24
```

there are 24 total values.

---

## 11. Connection to AI

Suppose later a batch of token IDs has shape:

```text
(32, 128)
```

This might mean:

```text
axis 0 → 32 sequences in the batch
axis 1 → 128 token positions per sequence
```

Later, after converting every token into an embedding vector, the shape may become:

```text
(32, 128, 768)
```

Now:

```text
axis 0 → batch
axis 1 → sequence
axis 2 → embedding/features
```

The important question is always:

> What does each axis represent?

---

## 12. Day 1 Mental Model

```text
scalar
→ one value

vector
→ one axis

matrix
→ two axes

tensor
→ general multidimensional numerical structure
```

And:

```text
shape
→ how large each axis is

ndim
→ how many axes exist

size
→ total number of values

axis
→ one direction through the structure
```

The main lesson is that AI data has structure, and tensor shape is how that structure is described.
