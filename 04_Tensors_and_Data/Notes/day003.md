## 2. Transpose

For a 2D matrix, transpose swaps rows and columns.

Example:

```python
import numpy as np

x = np.array([
    [1, 2, 3],
    [4, 5, 6]
])

print(x.shape)
# (2, 3)

x_t = x.T

print(x_t)
# [[1 4]
#  [2 5]
#  [3 6]]

print(x_t.shape)
# (3, 2)
```

The original shape:

```text
(2, 3)
```

becomes:

```text
(3, 2)
```

Mental model:

```text
rows ↔ columns
```

---

## 3. Transpose in Higher Dimensions

For higher-dimensional tensors, transpose means swapping selected axes.

In PyTorch:

```python
import torch

x = torch.randn(8, 20, 64)

# Original interpretation:
# axis 0 = batch
# axis 1 = sequence
# axis 2 = features
print(x.shape)
# torch.Size([8, 20, 64])

# Swap axis 1 and axis 2.
y = x.transpose(1, 2)

print(y.shape)
# torch.Size([8, 64, 20])
```

The values are not randomly changed.

Two axes change positions.

---

## 4. Permute

`permute` is more general than transpose.

Transpose:

```text
swap two axes
```

Permute:

```text
explicitly specify the complete new order of all axes
```

Suppose:

```text
(batch, sequence, features)
```

has shape:

```text
(8, 20, 64)
```

Using PyTorch:

```python
import torch

x = torch.randn(8, 20, 64)

# New order:
# old axis 1 first  -> sequence
# old axis 0 second -> batch
# old axis 2 third  -> features

y = x.permute(1, 0, 2)

print(y.shape)
# torch.Size([20, 8, 64])
```

Another rearrangement:

```python
# Keep batch first,
# move features second,
# move sequence third.

y = x.permute(0, 2, 1)

print(y.shape)
# torch.Size([8, 64, 20])
```

---

## 5. Transpose vs Permute

The distinction is:

```text
transpose
→ exchange two axes

permute
→ define the entire axis order
```

For a simple matrix, transpose is natural because there are only two axes.

For a tensor with several axes, permute can be clearer because I can state exactly where every axis should go.

This becomes important later when tensors represent things like:

```text
batch
heads
sequence
head_dimension
```

and the model needs a different axis order for a computation.

---

## 6. Matrix Multiplication Is Not Element-Wise Multiplication

This distinction is critical.

Element-wise multiplication:

```python
import numpy as np

A = np.array([
    [1, 2],
    [3, 4]
])

B = np.array([
    [5, 6],
    [7, 8]
])

print(A * B)
```

means:

```text
multiply matching positions
```

So conceptually:

```text
1×5   2×6
3×7   4×8
```

Matrix multiplication is different:

```python
print(A @ B)
```

It combines rows from the first matrix with columns from the second matrix.

So:

```text
A * B
```

and:

```text
A @ B
```

are different operations even when the shapes happen to be identical.

---

## 7. Matrix Multiplication Shape Rule

Suppose:

```text
A has shape (m, n)
B has shape (n, p)
```

Then:

```text
A @ B
```

has shape:

```text
(m, p)
```

The inner dimensions must match:

```text
(m, n) @ (n, p)
     ↑     ↑
     these must be equal
```

The outer dimensions survive:

```text
(m, n) @ (n, p)
  ↓             ↓
       (m, p)
```

A useful shorthand is:

```text
(m, n) @ (n, p) → (m, p)
```

---

## 8. Example of Valid Matrix Multiplication

Suppose:

```text
A shape = (20, 64)
B shape = (64, 8)
```

The inner dimensions are:

```text
64 and 64
```

They match.

So multiplication is valid.

The result shape is:

```text
(20, 8)
```

In code:

```python
import numpy as np

A = np.random.randn(20, 64)
B = np.random.randn(64, 8)

C = A @ B

print(C.shape)
# (20, 8)
```

Before running this, I should be able to predict the output shape.

---

## 9. Example of Invalid Matrix Multiplication

Suppose:

```text
A shape = (20, 64)
B shape = (8, 64)
```

Then:

```text
(20, 64) @ (8, 64)
```

The inner dimensions are:

```text
64 and 8
```

They do not match.

Therefore the matrix multiplication is invalid.

The important check is not:

```text
Do the matrices have the same shape?
```

The important check is:

> Does the number of columns in the first matrix equal the number of rows in the second matrix?

---

## 10. Square Matrices

A square matrix has the same number of rows and columns.

Examples:

```text
(2, 2)
(3, 3)
(64, 64)
```

This is called a **square matrix**.

Example:

```python
import numpy as np

A = np.array([
    [1, 2],
    [3, 4]
])

print(A.shape)
# (2, 2)
```

Being square is a property of one matrix.

It is not the rule that decides whether two matrices can be multiplied.

For example:

```text
(20, 64) @ (64, 8)
```

works even though neither matrix is square.

---

## 11. Determinant Is a Different Concept

A determinant is associated with a square matrix.

But determinant calculation is not what makes ordinary matrix multiplication work.

These are separate ideas.

For matrix multiplication, the rule is:

```text
columns of first matrix
=
rows of second matrix
```

The determinant belongs to a different part of linear algebra and answers different questions.

So I should not mix these ideas:

```text
square matrix
≠ matrix multiplication requirement

determinant
≠ method for multiplying mismatched matrices
```

---

## 12. Why the Output Shape Works This Way

Take:

```text
(20, 64) @ (64, 8)
```

The first matrix contains:

```text
20 rows
64 values per row
```

The second matrix contains:

```text
64 rows
8 columns
```

Each row of the first matrix can interact with each column of the second matrix because both contain 64 matching positions.

That produces:

```text
20 output rows
8 output columns
```

Therefore:

```text
(20, 8)
```

This is why the inner dimensions disappear and the outer dimensions remain.

## 13. Connection to Neural Networks

Later, one sample may contain several input features:

```text
[x1, x2, x3]
```

and a neuron may contain corresponding weights:

```text
[w1, w2, w3]
```

The neuron combines matching inputs and weights.

With many samples and many neurons, this naturally becomes matrix multiplication.

Conceptually:

```text
samples × features
@
features × neurons
=
samples × neurons
```

Shape example:

```text
(32, 64) @ (64, 128)
→
(32, 128)
```

Possible interpretation:

```text
32  → samples in the batch
64  → input features
128 → neurons / output features
```

This is one of the main reasons matrix multiplication appears everywhere in AI.
