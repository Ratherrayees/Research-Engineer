# Tensors & Data — Day 2

## Tensor Foundations: Scalars, Vectors, Matrices, Tensors, Shapes, Axes, Indexing, and Slicing

---

## 1. Why Tensor Structure Matters

AI systems do not work with isolated numbers for very long.

Data quickly becomes structured collections of numbers:

- one numerical value,
- a list of features,
- rows and columns,
- batches of samples,
- sequences of tokens,
- embeddings,
- model activations,
- parameter matrices.

The central lesson is:

> The values matter, but the structure of those values matters too.

That structure is described using ideas such as:

```text
scalar
vector
matrix
tensor
shape
axis
dimension
```

---

## 2. Scalar

A scalar is one numerical value.

Examples:

```text
5
0.01
-3.2
```

In AI, a scalar may represent:

- one learning rate,
- one loss value,
- one probability,
- one model parameter,
- one temperature value.

A scalar can be thought of as a 0D tensor.

```python
import numpy as np

x = np.array(5.0)

print(x.shape)  # ()
print(x.ndim)   # 0
```

The empty shape `()` means there are no axes around the value.

---

## 3. Vector

A vector is a one-dimensional ordered collection of numbers.

Example:

```text
[2.1, -0.4, 7.3]
```

With NumPy:

```python
import numpy as np

x = np.array([2.1, -0.4, 7.3])

print(x.shape)  # (3,)
print(x.ndim)   # 1
```

The shape `(3,)` means:

```text
one axis
size 3 along that axis
```

A vector may represent:

- features of one sample,
- several model weights,
- one embedding,
- one row of a dataset.

Important distinction:

```text
number of elements ≠ number of dimensions
```

A vector containing 10,000 values is still 1D.

---

## 4. Matrix

A matrix is a two-dimensional numerical structure.

Example:

```text
[
  [1, 2, 3],
  [4, 5, 6]
]
```

Shape:

```text
(2, 3)
```

Meaning:

```text
2 rows
3 columns
```

With NumPy:

```python
import numpy as np

x = np.array([
    [1, 2, 3],
    [4, 5, 6]
])

print(x.shape)  # (2, 3)
print(x.ndim)   # 2
```

A matrix may represent:

- samples × features,
- neural-network weights,
- an embedding table,
- several vectors collected together.

---

## 5. Tensor

In AI engineering, a tensor is usually understood as a multidimensional numerical container used for computation.

A useful mental model is:

```text
0D → scalar
1D → vector
2D → matrix
3D+ → higher-dimensional tensor
```

Example:

```python
import numpy as np

x = np.array([
    [
        [1, 2],
        [3, 4]
    ],
    [
        [5, 6],
        [7, 8]
    ]
])

print(x.shape)  # (2, 2, 2)
print(x.ndim)   # 3
```

The important point is not to imagine higher-dimensional tensors as mysterious physical objects.

Instead ask:

> What does each axis represent?

---

## 6. Shape

Shape tells us how many positions exist along every axis.

For:

```text
shape = (16, 100, 80)
```

we can read:

```text
axis 0 has size 16
axis 1 has size 100
axis 2 has size 80
```

The structure could represent:

```text
16 audio recordings
100 time steps per recording
80 features per time step
```

Structurally, it can also be visualized as:

```text
16 matrices
100 rows each
80 values per row
```

Both descriptions are valid, but the semantic interpretation is more useful in AI.

---

## 7. Dimension / Rank / `ndim`

The number of dimensions tells us how many axes a tensor has.

For:

```text
shape = (16, 100, 80)
```

there are three entries in the shape, therefore:

```text
ndim = 3
```

With NumPy:

```python
x = np.zeros((16, 100, 80))

print(x.ndim)
# 3
```

Do not confuse:

```text
number of dimensions
```

with:

```text
number of values
```

---

## 8. Axis

An axis is one direction of organization in a tensor.

For:

```text
shape = (32, 50, 768)
```

we may define:

```text
axis 0 → sentences
axis 1 → tokens
axis 2 → features
```

So:

```text
(32, 50, 768)
  ↑   ↑    ↑
  0   1    2
```

The axis number tells us which dimension we are referring to.

The axis size tells us how many positions exist along that dimension.

---

## 9. Shape vs `ndim` vs Total Size

These describe different things.

```python
import numpy as np

x = np.zeros((2, 3, 4))

print(x.shape)  # (2, 3, 4)
print(x.ndim)   # 3
print(x.size)   # 24
```

Meaning:

```text
shape → size of each axis
ndim  → number of axes
size  → total number of values
```

Because:

```text
2 × 3 × 4 = 24
```

---

## 10. Tensor Indexing

Indexing selects one specific position along an axis.

Suppose:

```text
x.shape = (32, 50, 768)
```

where:

```text
32  → sentences
50  → tokens per sentence
768 → features per token
```

Then:

```python
x[5]
```

selects index 5 along axis 0.

Because Python starts counting from zero, this is the sixth sentence.

The result shape becomes:

```text
(50, 768)
```

The sentence axis disappears because one specific sentence was selected.

---

## 11. Indexing Across Multiple Axes

Now:

```python
x[5, 10]
```

means:

```text
axis 0 → sentence index 5
axis 1 → token index 10
```

Result shape:

```text
(768,)
```

Only the token's feature vector remains.

Then:

```python
x[5, 10, 200]
```

means:

```text
sixth sentence
11th token
201st feature
```

The result is one scalar value.

So the pattern is:

```text
x                  → (32, 50, 768)
x[5]               → (50, 768)
x[5, 10]           → (768,)
x[5, 10, 200]      → scalar
```

Key rule:

> Selecting one specific index along an axis removes that axis from the result.

---

## 12. Slicing Keeps a Range

Indexing chooses one position.

Slicing chooses multiple positions.

```python
x[5:10]
```

selects indices:

```text
5, 6, 7, 8, 9
```

The result contains five sentences.

So:

```text
x.shape       = (32, 50, 768)
x[5:10].shape = (5, 50, 768)
```

Unlike selecting one exact index, slicing keeps the axis because the result still contains a collection of items along that axis.

---

## 13. Why Slice a Tensor?

There is nothing special about the numbers `5` and `10`.

A slice simply means:

> Work with this particular subset of the tensor.

Real uses include:

- selecting a batch,
- selecting a time window from audio,
- selecting part of an image,
- selecting a sequence range,
- shifting language-model inputs and targets,
- inspecting only part of a dataset.

Example:

```python
batch = x[0:8]
```

could select eight samples from a larger tensor.

---

## 14. Slicing Across Several Axes

Suppose again:

```text
x.shape = (32, 50, 768)
```

Then:

```python
y = x[5:10, 10:20, 120:150]
```

means:

```text
axis 0 → indices 5 through 9      → 5 items
axis 1 → indices 10 through 19    → 10 items
axis 2 → indices 120 through 149  → 30 items
```

Therefore:

```text
y.shape = (5, 10, 30)
```

Each axis is sliced independently.

A useful mental model is:

```text
original: (32, 50, 768)
             ↓   ↓   ↓
slices:    5:10 10:20 120:150
             ↓   ↓   ↓
result:      5   10   30
```

---

## 15. Orchard Mental Model

Imagine:

```text
32 apple trees
50 branches per tree
768 apples per branch
```

This has the same structural shape:

```text
(32, 50, 768)
```

Then:

```python
x[5:10, 10:20, 120:150]
```

means:

```text
select 5 trees
from each selected tree, select 10 branches
from each selected branch, select 30 apples
```

The resulting structure is:

```text
(5, 10, 30)
```

This analogy helps show that a tensor dimension is simply another level of organization.

---

## 16. What Happens to the Unselected Data?

If:

```python
y = x[5:10]
```

then `y` contains only that selected region.

But the original tensor `x` still contains all of its data.

Conceptually:

```text
x = entire dataset

y = selected window into part of x
```

Slicing does not automatically delete the other values from the original tensor.

---

## 17. Views and Copies

In PyTorch, ordinary slicing usually returns a **view** into the original tensor.

Example:

```python
import torch

x = torch.arange(10)
y = x[2:5]
```

`y` often refers to the same underlying storage as the corresponding region of `x`.

So an in-place modification can affect the original:

```python
y[:] = 0
```

The matching region of `x` also changes.

Mental model:

```text
view
→ another way of looking at the same underlying data
```

---

## 18. Assignment vs In-Place Modification

These two operations are different:

```python
y = y + 10
```

and:

```python
y[:] = y + 10
```

The first creates a new result and reassigns the name `y`.

The second writes into the existing view, so the corresponding part of the original tensor can change too.

This distinction becomes important when debugging tensor code.

---

## 19. Independent Copy with `.clone()`

If an independent PyTorch tensor is needed:

```python
y = x[2:5].clone()
```

Now `y` has its own storage for those values.

Conceptually:

```text
slice/view
→ shares underlying data

clone
→ independent copy
```

We do not need every memory detail yet, but this distinction is worth remembering.

---

## 20. AI Shape Meaning

A tensor like:

```text
(32, 50, 768)
```

should not be understood only as:

```text
32 matrices
50 rows
768 columns
```

In AI, ask what the axes mean:

```text
32  → batch/sentences
50  → token positions
768 → features per token
```

This is much more useful because later the same numerical shape may represent completely different data depending on the model.

The habit is:

> Read both the shape and the semantic meaning of each axis.
